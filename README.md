# Student Grade Management System

My third C programming project!

## Features
- Store marks of up to 100 students
- Validate student count and marks
- Calculate total marks
- Calculate average marks
- Find highest and lowest marks
- Assign grades to individual students
- Count passed and failed students
- Display a class summary

## Grading System
- A: 90–100
- B: 80–89
- C: 70–79
- D: 60–69
- F: 0–59

## Concepts Practiced
- Arrays
- Array indexing and traversal
- For loops
- If-else statements
- Logical operators
- Accumulators and counters
- Maximum and minimum calculations
- Floating-point arithmetic

## Language
C

## About
This project helped me practise arrays, loops, conditional statements and calculations by building a student marks management program.
